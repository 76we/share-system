## 一、本轮改动（按上线标准）

### 安全与鉴权

| # | 问题 | 改动 |
|---|---|---|
| 1 | `POST /topics` 公开可调，任何人能建话题 | `WebConfig` 删掉 `/topics/**` 整段排除；`LoginInterceptor` 改为「仅 GET /topics 放行」，写操作照常校验 token |
| 2 | 话题入参无校验，可写超长名称 / 空名 | `TopicController` 加非空 + 30 字长度校验，id/创建时间改服务端生成 |
| 3 | 任意来源带凭证跨域（`allowedOriginPatterns("*")` + credentials） | `WebConfig` 改读 `app.cors.allowed-origins`；dev 只放 `localhost:5173`，prod 默认空 = 完全不开跨域 |
| 4 | 上传只校验扩展名，改后缀的伪装文件能过 | `FileUtil` 重写：扩展名白名单 + 读文件头魔数（PNG/JPEG）+ 5MB 上限 + `lastIndexOf` 防越界 |
| 5 | 上传目录 `D:/uploads/` 硬编码在代码与资源映射里 | 统一到 `file.upload-dir`（dev 默认 `D:/uploads/`，prod 由 `UPLOAD_DIR` 注入），`WebConfig` 与 `FileUtil` 共用同一个配置项 |
| 6 | dev 明文数据库密码 / JWT 密钥进 git，prod 是占位符 | 全部改 `${...}` 环境变量；prod 缺失 `DB_PASSWORD` / `JWT_SECRET` 直接启动失败（失败得早好过带默认密钥上线） |
| 7 | 拦截器只认裸 token，第三方 `Bearer` 调不通 | `LoginInterceptor` 兼容 `Bearer xxx` 与裸 token 两种写法 |

### 稳定性与性能

| # | 问题 | 改动 |
|---|---|---|
| 8 | 分页 `size` 无上限，`?size=10000` 直传数据库；缓存 key 被无限放大 | `MybatisPlusConfig.setMaxLimit(50)` 全局兜底；`MomentServiceImpl.list` 入口归一化 `size ≤ 50`、`page ≤ 1000`（缓存 key 与内存排序不再被放大） |
| 9 | 好友照片墙 2N 次查询 | `PhotoWallServiceImpl.friendPhotos` 改成 4 次固定查询：批量取 owner → 过滤可见性 → 批量查动态 → 批量查图片 → 内存聚合 |
| 10 | `GlobalExceptionHandler` 吞异常不打日志，排障无据 | 业务异常 `log.warn`，其余 `log.error` 打完整堆栈；新增 404（资源不存在）/ 405（方法不支持），不再把「路径不存在」伪装成 500「系统繁忙」 |
| 11 | `user_like` / `user_collect` / `moment` 缺热路径索引 | 已加并复核：`user_like(target_id,target_type)`、`user_collect(moment_id)`、`moment(status,create_time)` |
| 12 | 生产无建表脚本，换机器恢复不了 | `src/main/resources/scripts/schema.sql`（11 张表结构 + 话题种子数据，UTF-8 无 BOM） |

### 功能补齐

| # | 问题 | 改动 |
|---|---|---|
| 13 | 后端有 `PUT/DELETE /moments/{id}`，前端零调用，发出去的帖子改不了也删不掉 | 详情页 + 个人中心「我的发布」加编辑/删除入口（仅作者可见，`commentUserId` 与 JWT `sub` 比对）；发布页支持 `?edit=id` 回填并 PUT 提交 |
| 14 | 评论接口是 `/api/comment`，靠 vite 剥前缀"巧合"对上 | 统一为 `/comments`，`userId` 一律从拦截器 `request.getAttribute("userId")` 取，不再各自解析 token |
| 15 | 前端 `axios.baseURL` 写死 `http://localhost:8080`，后端换端口即全站超时 | 改相对路径 `/api`，dev 走 vite proxy，prod 走 nginx 反代；8 个页面/组件的图片拼接同步改相对路径 |
| 16 | 无路由守卫，未登录能进发布页，登录后回不到原页 | `router.beforeEach`：无 token 只放行 `/login` 并带 `redirect`；已登录访问 `/login` 回 `/home` |
| 17 | 首屏单包 1.2MB | `vite.config.js` 加 `manualChunks` 拆 vue / element-plus / axios，首屏主包降到 78kB |

## 三、仍未做（按顺序建议）

5. **前端首屏**：Element Plus 全量引入（947kB）是最大头，可按需引入 `ElButton/ElDialog` 等组件再降一半。
