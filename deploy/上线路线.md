## 三条不能违反的纪律

1. **C2 的三个 `chown` 必须做对**（uploads→10001、mysql→999、redis→999）。
   错了后面全是 `Permission denied`，且报错位置和真实原因相差很远。
2. **两份 env 不要混**：`deploy/share-system.env` 给容器内应用，根 `.env` 给 compose。
   compose 的 `${VAR:-默认}` 插值读不到 `env_file` 里的变量。
3. **备份没演练过 = 没有备份**。E3 不是可选项。

## 卡住了怎么办

| 现象 | 先查 |
|---|---|
| `docker compose` 报 `permission denied` | 没加 docker 组，或加了没重新登录（`DEPLOY.md §8`） |
| 容器 `Created` 不动 | `docker compose logs mysql` 看是不是初始化失败或内存被杀 |
| 首页 502 | 后端没起来；`curl 127.0.0.1:8081/actuator/health` |
| 首页 404 但接口正常 | `root` 路径不对，或前端 dist 没传上去 |
| 图片全 404 | `UPLOAD_DIR` 与 nginx `alias` 不一致，两边都要 `/data/uploads` |
| 上传 413 | `client_max_body_size` 小于 48m |
| 时间差 8 小时 | compose 少了 `--default-time-zone=+08:00` |
